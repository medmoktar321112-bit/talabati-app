# طلباتك — نسخة أولية

واجهة عربية RTL لمتجر/سوق محلي، مبنية بـ React + Vite وSupabase Auth/Database.

## ما الذي يعمل؟
- واجهة عربية متجاوبة.
- عرض منتجات تجريبية قبل ربط قاعدة البيانات.
- إنشاء حساب وتسجيل الدخول بالبريد وكلمة المرور عبر Supabase.
- قراءة المنتجات من قاعدة البيانات بعد الإعداد.
- لوحة مالك لإضافة المنتجات وحذفها.
- صلاحيات قاعدة البيانات تُفرض بواسطة Row Level Security (RLS)، لا بمجرد إخفاء الأزرار في الواجهة.

## 1) المتطلبات
- Node.js 18 أو أحدث
- حساب Supabase ومشروع جديد

## 2) تشغيل المشروع
```bash
npm install
cp .env.example .env
```
افتح `.env` وأدخل عنوان مشروع Supabase ومفتاح `anon`/publishable من إعدادات المشروع. لا تضع `service_role` key في الواجهة أبدًا.

ثم:
```bash
npm run dev
```
افتح عنوان Vite الذي يظهر في الطرفية.

## 3) إعداد قاعدة البيانات
1. في Supabase افتح SQL Editor.
2. شغّل محتوى `supabase/schema.sql`.
3. من Authentication > Providers تأكد من تفعيل Email.
4. سجّل حسابك من واجهة التطبيق. إن كان تأكيد البريد مفعّلًا، أكّد البريد أولًا.

## 4) ترقية حسابك إلى مالك التطبيق
1. افتح Supabase Dashboard > Authentication > Users.
2. ابحث عن بريد حسابك وانسخ قيمة User UID.
3. افتح SQL Editor وشغّل الأمر التالي بعد استبدال `YOUR-USER-UUID` بمعرّف حسابك الحقيقي:

```sql
update public.profiles
set role = 'owner'
where id = 'YOUR-USER-UUID';
```

4. سجّل الخروج ثم الدخول مرة أخرى أو حدّث الصفحة. سيظهر زر «إضافة منتج» لحساب المالك.

**لا تضف نموذجًا عامًا لتعيين الدور `owner`، ولا تضع كلمة مرور المالك في الكود.** إنشاء المالك يتم يدويًا من لوحة Supabase الموثوقة. لا تشارك حساب المالك.

## 5) تنبيهات قبل الإطلاق
- المنتجات التجريبية مجرد بيانات توضيحية.
- لا توجد حاليًا طلبات شراء أو دفع إلكتروني أو رفع صور إلى تخزين سحابي.
- رابط الصورة يُحفظ كعنوان URL فقط؛ أضف Supabase Storage إذا أردت رفع الملفات.
- قبل الإنتاج، أضف التحقق من المدخلات ومراقبة الأخطاء وحدودًا لمعدل الطلبات، وسياسة خصوصية وشروط استخدام.
- اختبر سياسات RLS بحساب عادي: يجب ألا يتمكن من إضافة/تعديل/حذف المنتجات.
